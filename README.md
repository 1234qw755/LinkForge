# LinkForge
简洁的第三方节点直链生成器，仅负责链接转换，不托管文件，存储与流量由上游节点提供，请遵守相关协议与法规。/ A simple direct link generator based on third-party nodes. It only converts links and does not host files. Storage and traffic are provided by upstream nodes. Please comply with relevant agreements and regulations. The software currently only supports Chinese.
